## 3. 人工体验脚本

前置：本地后端 + 前端 + 真实 provider（opencode 或 OpenAI 兼容）；使用获授权测试账号。

1. 登录 → 打开项目 → 进入准备页，打开 AI 面板。
2. 未配置模型时确认只显示“去设置”，没有空输入框。
3. 配置模型后发送“看看我的项目文件”，确认工具卡出现并可展开。
4. 请求“把某段改成……”，确认建议卡出现；应用后刷新文件树与编辑器。
5. 再次修改稿件后应用旧建议，确认转为过期且不覆盖。
6. 发送一条长回答，中途点击停止，确认“正在停止”与取消终态。
7. 刷新页面，确认文本、工具卡、建议卡与取消状态一致。
8. 快速切换两个会话，确认没有串消息；点击“新对话”确认空白。
9. 流式中断开网络 10 秒再恢复，确认重连与去重。
10. 两个标签页同时发送，确认 409 后显式重试。
11. 重启后端，确认遗留 Run 收敛、页面不悬挂。
12. 用错误 key、限流、超时、超长上下文分别触发错误，确认提示可操作。

## 4. 证据要求

- 每项记录：版本/提交、环境、账号（脱敏）、时间、操作、结果、截图/日志路径。
- 真实 provider 记录模型名与请求时间；不记录密钥与完整用户内容。
- 失败项保留原始错误与复现步骤；不得删除反例。
- 未执行项在最终报告中单列，不用“CI 通过”代替。
