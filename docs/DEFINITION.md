# 课题简介
学术论文写作是本科生完成毕业设计、研究生开启科研生涯的核心必备能力，也是检验专业知识应用、科研思维与逻辑表达能力的核心标准。本科生与刚接触科研的研究生作为学术写作的核心新手群体，普遍面临着共性痛点：多为首次接触规范化学术写作，对学术写作规范与核心方法缺乏系统认知，专业写作能力不足，面对各类论文写作任务普遍无从下手。大语言模型凭借成熟的自然语言理解、逻辑梳理、规范文本生成与优化能力，为破解科研新手的写作入门痛点提供了可行的技术路径。利用大模型为学生群体提供全流程的写作引导与辅助，既能有效降低学术写作的入门门槛，规范写作流程，提升文本质量与创作效率，也能帮助学生聚焦核心研究内容的打磨，同时减轻导师重复性的基础指导工作负担，兼具工程落地性与广泛的实际教学、科研应用价值。
本课题设计并实现一套前后端分离的Web系统，将大模型能力与科研论文写作全流程深度结合，打造适配科研新手群体的专属AI辅助写作工具。核心研究内容包括：1）设计并实现一套前后端分离的科研论文写作AI辅助系统，完成用户管理、分场景写作工作台、全流程AI写作辅助、学术规范资源库等核心业务模块的开发；2）完成主流大语言模型的接入，针对本科生毕设论文、入门级学术小论文等核心场景，完成全写作流程的专属prompt优化；3）完成系统全流程的功能、性能、可用性等测试。
