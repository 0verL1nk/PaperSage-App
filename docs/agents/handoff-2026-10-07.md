# Handoff（2026-10-07）：写作工作台、本地游客与响应式收尾

> 本文记录 worktree `claude/reverent-cori-fccda6` 的当前实现及已运行检查。游客模式的产品决策是：线上正式站点提供免注册入口，项目内容仅保存在当前浏览器；用户登录后显式预览并确认导入账号。

## 已实现

- 项目创建可选本科毕业论文或学术小论文场景；工作台提供写作准备、撰写、检查三个阶段，准备状态通过项目写作状态接口持久化，阶段可切换，旧入口重定向到新阶段页面。
- 登录/注册页使用动态渐变网格背景并尊重 `prefers-reduced-motion`。认证表单、游客入口、项目弹窗和移动阶段导航在窄视口下允许纵向滚动，关键触控目标至少 44px。
- 正式网站游客入口先初始化 IndexedDB，再进入本机工作区。项目、写作状态、资料文件 Blob、文件夹及 LaTeX 源文件保存在当前浏览器。游客无服务端账号、匿名会话或 bearer token，项目编辑不上传云端。刷新可恢复；更换设备或清理浏览器站点数据后无法恢复。
- 游客可在本机建立项目、编辑准备/阶段状态、整理资料及编辑 LaTeX 源文件。AI、在线编译、云端 PDF 和项目分组需要账号或暂不可用，界面说明边界。IndexedDB 初始化/写入失败会提示原因；浏览器配额因环境而异。
- 登录/注册后显示当前接收账号和待导入项目预览；用户确认后按项目逐项导入并保留续传映射。项目、文件夹、资料、LaTeX 创建使用服务端幂等回执，断线重试不会重复创建；写作状态可安全重放。失败时保留本地源数据。成功后默认保留本机备份，删除需二次确认；本地回收站项目导入后仍保持回收站状态。
- 服务端游客账号、token 分支、清理任务、游客配额及相关配置已移除；写作工作台迁移和账户导入幂等回执迁移保留。PG/MySQL fresh install 与 handoff migration 由隔离集成环境验证。

## 验证记录

- 后端：`go vet ./...`、`go test ./internal/... ./web/...` 通过。PG 与 MySQL 8.4 的 fresh/handoff migration 集成测试由隔离服务运行并通过；未使用或覆盖 `server/e2e-go.db`。
- 前端：`pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 通过。Vitest 为 33 个文件、208 passed、1 skipped。生产构建提示 Monaco/编辑器 bundle 大于 500 kB，这是非阻塞体积告警。
- Chromium 响应式 E2E：最终全套 5 passed，覆盖认证/游客入口、本机游客创建与刷新恢复、账号导入预览弹窗、云端写作工作台。视口为 320×640、390×844、768×1024、1024×768、1440×900；检查横向溢出、主操作可达、触控高度、固定导航遮挡、阶段导航、编辑器宽度、写作状态恢复和游客模式不调用内容 API。
- 游客导入服务单测覆盖稳定导入头、完整资源导入、按映射续传、单项失败保留进度、回收站状态保留。服务端导入回执单测覆盖同键重放及内容冲突。导入界面使用用户授权流程；E2E 未连接真实生产数据库、对象存储或 SMTP。
- `git diff --check` 与 `openspec validate online-guest-workspace`、`openspec validate writing-workbench-foundation` 通过。

Makefile 指定的 `make` 命令在当前 Windows shell 不可用，因此运行了等价的 Go 与 pnpm 命令。开始任务前 `server/e2e-go.db` 已有用户改动，本次保留，没有测试写入该文件。

## 发布前仍需实环境验收

- 生产 SMTP 邮件实际送达及注册验证链接闭环。
- 生产数据库迁移窗口、SECRET_KEY、代理可信 IP、对象存储权限/备份与生命周期配置。
- 真实 AI provider、CLSI 编译器和对象存储环境下的登录用户能力；浏览器响应式与游客隔离 E2E 使用本地服务/mock，不代表生产服务可用。
- 浏览器本地数据受站点存储策略约束，公开/共享设备不适合放敏感材料；用户应在重要内容完成后尽早导入账号。
