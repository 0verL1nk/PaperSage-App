# 本地游客工作区

更新：2026-10-07。游客入口运行在 PaperSage 正式网站，但游客项目不是云端试用账号：项目、写作准备状态、资料文件及其 Blob、LaTeX 源文件和导入映射保存在当前浏览器的 IndexedDB。游客使用不创建服务端身份，不携带游客 token，也不将上述内容上传到服务端。

## 入口与可用能力

登录卡片中的“免注册体验 PaperSage”会直接初始化 IndexedDB 并进入项目列表；用户不需要先阅读单独介绍页再点击一次。若用户直接打开 `/guest`，页面也会立即初始化并跳转。只有浏览器不支持或拒绝本地存储时，才显示错误与重试操作。

游客可以在本机创建项目，维护写作准备/阶段状态，添加文件夹与资料文件，并编辑 LaTeX 源文件。新项目会在创建事务中同时写入默认 `main.tex`；写作页读取失败时会显示原因和重试入口，不会把存储错误伪装成空文件树。IndexedDB 结构版本为 2，会为已有数据库补齐缺失的文件索引并保留已有文件。刷新页面后，同一浏览器配置中的本地数据继续可用。项目分组暂不支持。AI 服务、在线 LaTeX 编译和云端 PDF 请求需要账号；游客界面会提示登录要求，不会为调用这些能力而自动上传草稿。

IndexedDB 是浏览器站点存储。清理站点数据、使用隐私浏览模式、浏览器回收空间或更换浏览器/设备，都可能使游客数据无法恢复。游客入口和工作区应明确标注“本机保存/未同步”，并在无法访问存储或空间不足时给出可操作的错误提示。不要向用户承诺所有浏览器统一的存储额度。

## 导入账号

用户登录或注册后，应用可读取当前浏览器中的游客工作区，并展示待迁移项目及其资料、LaTeX 文件等摘要。界面必须标明接收数据的账号，只有用户确认后才逐项上传。导入过程顺序执行并保存进度；可重试失败项，不能因为部分失败删除本地原件。成功后默认保留本机副本，用户可以另行确认删除。

项目、文件夹、资料和 LaTeX 创建请求使用 bundle UUID 与本地项目项 UUID 作为幂等键。服务端将同键同内容重试映射到原资源，避免网络中断或刷新造成重复创建；同键内容发生变化时返回冲突。详细接口约定见[本地导入幂等性](../backend/local-import-idempotency.md)。写作状态通过项目级保存接口迁移。导入按单项完成，不是全 bundle 原子事务。

账号会话恢复时，当前 access token 优先于已废弃服务端游客流程留下的旧标记；旧标记会被清除，已有的游客导入待办状态和 IndexedDB 内容仍保留。带账号 token 访问 `/guest` 会直接跳转到项目页。

如需扩展本地游客能力，应在服务 API 层按游客会话路由到本地实现，避免页面组件意外直连云端 API；同时覆盖刷新恢复、无网络调用、存储错误和导入重试。新增账号导入类型时，应提供稳定本地 ID、服务端幂等创建，以及可恢复的本地进度映射。
