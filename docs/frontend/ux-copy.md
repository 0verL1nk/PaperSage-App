# 前端用语与文案规范

面向本科生的界面只用写论文时会说的词。本文是唯一口径:新增或修改文案先查这里,再查 `frontend/src/i18n/locales/zh-CN.json` 与 `frontend/src/services/errors.ts`。

## 术语对照（唯一说法）

| 不要用 | 用 | 说明 |
|---|---|---|
| 产物 / 研究产物 / 组织产物 | **整理记录**；按类型称「阅读记录 / 文献比较 / 章节计划 / 章节摘要」 | 卡片标题用「资料整理」 |
| 修订 / 新修订 | **修改**（保存修改 / 这次修改 / 版本） | 「版本」只用于确实指代版本的地方 |
| 候选 | **待确认** | 「已采用」保留 |
| 拒绝 | **忽略** | 与写作建议的「忽略」一致 |
| 会话 | **对话** | 「会话已建立」直接删掉 |
| 本地确定性检查 / 本地规则 | **格式与结构自检** | 必须保留一句「按固定清单自动核对，不评价内容」，不能伪装成 AI |
| 置信度低 | **依据较弱，请重点核对** | |
| 维度 | **检查项** | 维度名称本身保留 |
| 工具调用 / 推理 | **执行步骤 / 检查过程** | 原始工具名与 JSON 只放在「技术细节」折叠里 |
| 服务端默认 | **默认模型** | 学生不需要知道部署形态 |
| 标识（slug） | 隐藏，自动生成 | 规范包标识由前端生成,用户只填名称 |
| 上下文窗口（tokens） | **记忆长度（tokens）** | |
| 运行记录 / 对话记录 / 工具调用记录 | **这次回答 / 这条消息 / 助手的操作记录** | |
| 您 | **你** | 全站统一 |
| 上传资料（导航） | **资料库** | 「上传」只用于按钮动作 |
| 本地后端不可用 | **预览暂时不可用** | |
| 游客数据库 | **本机游客数据** | 数据安全告知保留 |

规范引用号（如 `N-xxx@v3`）在「依据」详情里保留,用于学术追溯;列表徽标不显示版本号。

## 写法规则

- 人称统一用「你」,不用「您」。
- 一句话说清一件事;超过两行的解释先问是否必要。
- 错误提示 = 发生了什么 + 能怎么办;技术细节收进「技术细节」折叠,不直接把堆栈、CORS、HTTP Range、profile id 甩给用户。
- 空态必须给出下一步动作,不留死胡同。
- 破坏性操作要二次确认,并说清会丢什么。
- 不把固定规则检查包装成 AI 判断,也不把 AI 结论说成「已核对」。

## 文案的三个来源（改一处不够）

1. 页面与组件里的 JSX 字面量（大部分页面）;
2. `frontend/src/i18n/locales/zh-CN.json` 与 `en-US.json`（导航、设置、AI 设置,中英同一提交改）;
3. `frontend/src/services/errors.ts` 的后端错误串 → 中文映射（用户看到的大多数报错来自这里）。后端新增错误串必须补映射,否则英文原文会直接透出。

## 自动化守门

`frontend/eslint.config.js` 的 `no-restricted-syntax` 会拦截新增的「产物 / 会话 / 您 / 置信度 / 确定性」字面量;确属必要的技术文案（如 AI 设置里的接口字段）加 eslint-disable 并注明原因。
