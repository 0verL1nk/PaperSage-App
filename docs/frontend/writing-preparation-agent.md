# 写作准备：研究顾问对话

写作准备以对话作为主流程，不让科研新手面对一组空字段自行设计研究计划。用户可以从兴趣、困惑、任务书、导师意见或已上传材料开始；Agent 先读取项目已有状态，再通过一轮一个重点的追问澄清范围和可行性。

Agent 需要把已知事实、建议、假设和待验证信息分开处理。形成草案后先完整展示给用户；只有用户明确确认后，才调用 `save_writing_preparation` 保存研究蓝图与课题要求。保存时使用写作状态 revision，冲突时重新读取，不能静默覆盖。未讨论课题要求时保留已有内容；工具不会自动改变阶段状态或 LaTeX 稿件。

准备页侧栏展示已保存内容、待探索方向与材料状态，内容通过对话逐步形成。游客数据仍只保存在本机浏览器；当前服务端 Agent 需要登录账号和可用模型配置，所以游客页面仅展示当前蓝图并说明能力边界。

新建项目会自动初始化 `main.tex`。如果模板的对象存储或元数据写入失败，创建请求需要明确失败并清理新项目记录；不得返回缺模板的“成功”项目。空文件树必须保留创建入口，文件和文件夹写入失败要在页面可见。

能力契约见 [OpenSpec 变更](../../openspec/changes/agentic-writing-preparation/)。
