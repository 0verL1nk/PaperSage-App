## ADDED Requirements

### Requirement: 导入本地文件夹
客户端 SHALL 允许用户选择一个本地文件夹，并将其中的受支持文件导入当前项目的参考资料库。导入 SHALL 复用现有上传 API、类型校验与进度反馈；单个文件失败 SHALL 不阻断其余文件，并在结束时汇总成功与失败数量。

#### Scenario: 导入包含受支持文件的文件夹
- **WHEN** 用户选择包含 PDF 与 DOCX 的文件夹并确认导入
- **THEN** 受支持文件逐个上传，界面显示总体进度，完成后汇总结果

#### Scenario: 文件夹包含不支持的文件
- **WHEN** 文件夹中包含图片、可执行文件或其他不在白名单内的类型
- **THEN** 这些文件被跳过，汇总中列出跳过数量，不上传

#### Scenario: 部分文件失败
- **WHEN** 上传过程中部分文件因网络或服务端错误失败
- **THEN** 其余文件继续上传，结束时列出失败文件与原因，可重试

### Requirement: 导出项目
客户端 SHALL 允许用户将当前项目的 LaTeX 源文件与参考资料导出到本地文件夹。导出内容 SHALL 来自服务端当前数据，生成压缩包后通过系统保存对话框写入用户选择的位置。导出失败 SHALL 保留可重试状态，不得写入不完整文件覆盖已有文件。

#### Scenario: 成功导出
- **WHEN** 用户选择导出项目并指定保存路径
- **THEN** 生成包含 LaTeX 源文件与参考资料的压缩包，写入指定位置，并提示完成

#### Scenario: 取消保存
- **WHEN** 用户在保存对话框中取消
- **THEN** 不写入任何文件，界面回到未导出状态

#### Scenario: 导出过程中网络失败
- **WHEN** 拉取项目文件时请求失败
- **THEN** 提示失败原因，不生成或覆盖目标文件，可重新导出

### Requirement: 在文件管理器中显示
客户端 SHALL 提供“在文件管理器中显示”操作，用于定位最近导出目录或其他用户明确选择的本地路径。该操作 SHALL 只接受本次会话中由用户选择或由应用生成的路径。

#### Scenario: 显示导出目录
- **WHEN** 导出完成后用户选择“在文件管理器中显示”
- **THEN** 系统文件管理器打开并选中导出文件或目录

#### Scenario: 拒绝任意路径
- **WHEN** 前端请求显示一个未由用户选择、也非应用生成的路径
- **THEN** 操作被拒绝

### Requirement: API 目标切换与持久化
客户端 SHALL 保留现有的远程/本地 API 目标切换能力，并在重启后恢复用户上次选择。客户端托管的本地后端 SHALL 作为本地目标的默认实现。使用不可达的 API 地址时 SHALL 显示明确错误与当前生效地址，不得表现为空白页或无限加载。

#### Scenario: 切换到本地后端
- **WHEN** 用户把 API 目标切换为本地并重启客户端
- **THEN** 客户端继续使用本地地址，并在“关于”中显示该地址

#### Scenario: 目标不可达
- **WHEN** 当前 API 地址无法连接
- **THEN** 界面显示连接失败、当前地址与切换入口

### Requirement: 离线与错误反馈
客户端 SHALL 在网络不可用时给出可理解的状态提示。依赖服务端的功能 SHALL 明确失败；浏览器游客工作区等本地能力 SHALL 保持可用，不因网络失败被清空。

#### Scenario: 断网启动
- **WHEN** 用户在没有网络连接时启动客户端
- **THEN** 已登录状态下的数据请求显示网络错误，本地游客数据仍可访问

#### Scenario: 请求超时
- **WHEN** API 请求超过约定超时时间
- **THEN** 显示超时提示并提供重试，不无限等待
