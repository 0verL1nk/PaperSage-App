## ADDED Requirements

### Requirement: 本地后端二进制与版本匹配
客户端 SHALL 随安装包分发与客户端版本一致的后端二进制，并在启动本地模式前校验版本。缺失或版本不一致时 SHALL 拒绝启动本地后端，明确提示原因并回退到远程模式，不得使用不兼容的旧后端。

#### Scenario: 版本一致时启动
- **WHEN** 客户端与后端二进制版本一致
- **THEN** 客户端启动本地后端并进入就绪状态

#### Scenario: 版本不一致
- **WHEN** 后端二进制缺失或版本与客户端不一致
- **THEN** 客户端不启动本地后端，提示升级或重新安装，并允许切换到远程 API

### Requirement: 本地后端生命周期
客户端 SHALL 负责本地后端的启动、健康检查和退出清理。本地后端 SHALL 只监听回环地址，使用应用数据目录下的数据库与日志。客户端退出时 SHALL 优雅停止后端；后端异常退出时 SHALL 有限次数退避重启，超过上限后停止重试并提示用户。

#### Scenario: 正常启动
- **WHEN** 客户端冷启动且本地后端可用
- **THEN** 客户端启动后端、轮询健康检查，就绪后允许前端发起请求

#### Scenario: 退出清理
- **WHEN** 用户从托盘或菜单退出客户端
- **THEN** 客户端先请求后端优雅退出，超时后强制结束，不残留后台进程

#### Scenario: 后端崩溃
- **WHEN** 本地后端进程意外退出
- **THEN** 客户端按退避策略重启；连续失败超过上限后停止重试并提示用户

#### Scenario: 端口被占用
- **WHEN** 默认端口已被其他进程占用
- **THEN** 若占用者不是本项目后端，客户端选择空闲端口并把实际地址提供给前端；若是本项目后端，则复用

### Requirement: 本地后端地址注入
客户端 SHALL 把实际生效的本地后端地址提供给前端，并保留用户显式设置的 API 地址优先级。用户显式选择远程或自定义地址后，客户端 SHALL NOT 用本地后端地址覆盖该选择。

#### Scenario: 默认使用本地后端
- **WHEN** 用户未显式设置 API 目标且本地后端就绪
- **THEN** 前端请求默认发往客户端托管的本地后端

#### Scenario: 用户选择远程
- **WHEN** 用户把 API 目标切换为远程并重启客户端
- **THEN** 客户端仍使用远程地址，不启动或不使用本地后端

### Requirement: 编译不依赖本机 TeX
客户端 SHALL NOT 检测、依赖或调用用户本机安装的 TeX 发行版与 `latexmk`。编译 SHALL 使用项目自带的浏览器 WASM 引擎；若用户显式配置了 CLSI，则按既有逻辑使用 CLSI。客户端 SHALL NOT 因未检测到本机 TeX 而阻止编译。

#### Scenario: 用户未安装 TeX
- **WHEN** 用户机器上没有 TeX Live 或 MiKTeX
- **THEN** 编译照常通过自带 WASM 完成，界面不提示安装 TeX

#### Scenario: 用户安装了 TeX
- **WHEN** 用户机器上存在 TeX 安装
- **THEN** 客户端不读取也不调用它，编译行为与未安装时一致

#### Scenario: WASM 引擎不可用
- **WHEN** WebView2 无法运行 WASM 编译链路
- **THEN** 客户端明确报错并给出排查信息，不静默回退到用户本机 TeX

### Requirement: 本地数据与日志目录
客户端托管的本地后端 SHALL 使用应用数据目录存放数据库与日志，并在“关于”或诊断页面展示这些路径。卸载时 SHALL 按约定保留用户数据或明确提示清理方式。

#### Scenario: 数据目录可定位
- **WHEN** 用户打开诊断或关于页
- **THEN** 能看到本地数据库与日志路径

#### Scenario: 卸载不静默删数据
- **WHEN** 用户卸载客户端
- **THEN** 用户数据按约定保留或由安装器明确询问是否删除
